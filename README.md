One line of text, 1 to 240 characters, that gives the judge a quiet, earned moment of pride for someone in a scene — a small person doing something hard, a long effort finally landing. Free to enter, $5 shared by the top 10 lines.

This entry sends one line: a seventy-two-year-old father, three months out of hospital, carrying the groceries up all four flights, refusing the lift, and setting the bags down grinning like he'd stolen something — pride earned on the stairs, landing in the last image.

## Run it

```sh
python3 main.py
```

The program writes exactly that one line (180 characters) to `/output/entry.txt`. Pure Python standard library, deterministic: no input, no randomness, no clock, no network.
